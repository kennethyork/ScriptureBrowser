# ============================================================================
#  Scripture Browser — the sites this browser is allowed to open.
# ============================================================================
#
#  WHAT THIS IS
#
#  A list of what serves the reading of Scripture, the study of it, the worship
#  of God, and the ordinary Christian life.  Nothing else belongs on it.
#
#  WHAT IS NOT ON IT, ON PURPOSE
#
#  General-purpose sites.  Encyclopaedias, dictionaries, news, search engines —
#  useful, but they are the opposite of a room built for one thing.  A browser
#  that can reach everything is not centred on anything.
#
#  Places that host everything.  Free libraries, video sites, social media,
#  shops, forums.  A site is allowed *whole* here — every page of it — so a site
#  that hosts everything is a site that allows everything.
#
#  If you add one of those back, build.py will say so out loud, and
#  `scripture-browser --add` will refuse it.  That is a nudge, not a rule: this
#  is your list, and editing this file by hand always works.
#
#  HOW TO WRITE A LINE
#
#     biblegateway.com # Bible Gateway        <- a site, and its name
#     biblegateway.com                        <- a site, no name
#     ## Scripture                            <- a heading, groups the lines
#     # a comment
#
#  One domain per line.  No http://, no paths, no trailing slash — just the host.
#  A bare domain allows that host and its "www." twin; a subdomain that matters on
#  its own (my.example.com) needs its own line.  Removing a line removes the site
#  from the browser, the start page and the filter at once:
#
#      sudo scripture-browser --update
#
# ============================================================================

## Browser plumbing — leave these alone

# Not places to visit: these carry Firefox's own protection data — the Safe
# Browsing lists, the blocklists behind tracking protection, and the signatures
# that make them trustworthy.  They are kept off the start page and out of the
# bookmark bar by build.py, which reads this very heading.
#
# Firefox updates are not here.  A clone never updates itself; the package
# manager patches the machine's Firefox and the clone is re-vendored from it.
firefox.settings.services.mozilla.com        # Remote settings — blocklists, safe browsing
firefox-settings-attachments.cdn.mozilla.net # the attachments those settings point at
content-signature-2.cdn.mozilla.net          # the signatures over them
